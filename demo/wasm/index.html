AOM-PLS browser demonstration

Interactive comparison of raw PLS and AOM-PLS

Bring separate calibration and validation X/y files, inspect them, then run both methods on the same split. The page reports the only modelling difference: AOM-PLS screens a linear spectral operator before fitting PLS. A documented example is available when you do not have files at hand.

The winner is folded back to the original feature grid. Deployment predicts directly from raw X; no preprocessing pipeline must be replayed.

04

Scope

Reproducibility and limits

This companion is deliberately narrower than the paper benchmark. It makes one complete calibration auditable and portable.

01

Traceable inputs

The bundled snapshots point to their exact nirs4all source. Uploaded files are parsed locally and never transmitted.

02

Comparable models

Both routes see the same X, y, folds and validation rows. The displayed metrics come only from the held-out partition.

03

Native browser fit

AOM selection calls the n4m native C ABI compiled to WebAssembly; raw PLS uses the same portable engine.

04

Deployable outcome

AOM returns original-grid coefficients and an intercept, so raw spectra can be predicted without replaying preprocessing.

Scope note

Illustration, not a benchmark claim

The included datasets were generated to exercise nirs4all formats and spectral metadata. Results can favor either route and should not be generalized. See the paper and supplementary material for the multi-dataset evaluation.

Use AOM in your own workflow

Python package

Reproduce the held-out comparison

The sklearn-compatible package selects the AOM operator and component count by calibration CV, then predicts your untouched validation rows.

python -m pip install nirs4all-aom pandas scikit-learn
compare_aom.py
import numpy as np
import pandas as pd
from sklearn.cross_decomposition import PLSRegression
from sklearn.metrics import mean_squared_error
from sklearn.model_selection import GridSearchCV, KFold
from aom_nirs.pls import AOMPLSRegressor

def read_x(path):
    return pd.read_csv(path, sep=None, engine="python").to_numpy(float)

def read_y(path):
    return pd.read_csv(path, sep=None, engine="python").iloc[:, 0].to_numpy(float)

Xcal, ycal = read_x("Xcal.csv"), read_y("Ycal.csv")
Xval, yval = read_x("Xval.csv"), read_y("Yval.csv")
cv = KFold(n_splits=5, shuffle=False)
budget = range(1, min(15, Xcal.shape[1], len(Xcal) - 1) + 1)

raw = GridSearchCV(
    PLSRegression(scale=False), {"n_components": budget},
    cv=cv, scoring="neg_root_mean_squared_error"
).fit(Xcal, ycal)

aom = AOMPLSRegressor(
    n_components="auto", max_components=max(budget),
    operator_bank="compact", criterion="cv", cv=5,
    cv_splitter=cv, random_state=0
).fit(Xcal, ycal)

for name, model in {"Raw PLS": raw, "AOM-PLS": aom}.items():
    pred = np.asarray(model.predict(Xval)).ravel()
    rmsep = np.sqrt(mean_squared_error(yval, pred))
    print(f"{name:8s} RMSEP = {rmsep:.4g}")

print("AOM operator:", aom.selected_operators_)
print("AOM components:", aom.n_components_)

If your files do not contain a header row, add header=None to each read_csv call.

R package

Run the native AOM selector

The current R interface exposes the native calibration fit, operator selection and CV diagnostics. Held-out prediction from the selected original-grid model is currently provided by the browser and Python interfaces.

install.packages("n4m", repos = c("https://gbeurier.r-universe.dev", getOption("repos")))
compare_aom.R
library(n4m)

read_x <- function(path) as.matrix(read.csv(path, check.names = FALSE))
read_y <- function(path) read.csv(path)[[1L]]

Xcal <- read_x("Xcal.csv")
ycal <- read_y("Ycal.csv")

aom <- aom_pls(
  Xcal, ycal,
  max_components = 15L,
  n_operators = 9L,
  cv = 5L
)

cat("Selected operator index:", aom$selected_operator_index, "\n")
cat("Selected components:", aom$selected_n_components, "\n")
cat("Calibration CV RMSE:", aom$best_score, "\n")
plot(aom$rmse_curves, type = "l", xlab = "Candidate", ylab = "CV RMSE")

For semicolon-delimited decimal-comma files, replace read.csv with read.csv2.
