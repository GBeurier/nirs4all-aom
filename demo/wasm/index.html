03 · Audit trail

What this page proves

  • The fit calls the native n4m_model_selection_aom_pls_select path compiled to WebAssembly.
  • The default bank contains identity, polynomial detrending, Savitzky–Golay smoothing, Savitzky–Golay derivative and finite difference.
  • The returned coefficients live on the original wavelength grid and predictions use the raw held-out spectra.
  • No observations or spectra leave the browser.
