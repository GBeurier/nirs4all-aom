# Reproducing the research methods

See [../REPRODUCTION.md](../REPRODUCTION.md) for installation and numerical
validation, and [../benchmarks/README.md](../benchmarks/README.md) for generic
benchmark guidance. Record the exact code revision, input provenance, operator
bank, validation splits, environment and output paths for each experiment.

Manuscripts, frozen paper cohorts, publication results and their build scripts
are maintained privately in `nirs4all-drafts` until submission.
